Delegated Coding Tasks

Fixing failing CI, upgrading dependencies, and fixing filed issues require a genuinely capable coding model. GitHub Copilot cloud agent is the most capable option (multi-turn, can run tests, iterate on CI failures). A local Lemonade model (Qwen3-Coder) is also available as a no-subscription-required option — it works in a single best-effort pass (no tool use or test iteration) using the repo's file contents and opens its own PR. All three toggles below are opt-in and off by default — review the PRs they open before merging.
