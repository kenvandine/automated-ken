Testing Configuration

YARF test suites now live colocated with each snap's packaging repo, under tests/suite/, alongside a .github/workflows/snap-test.yml workflow. Tests are triggered automatically against each snap's own packaging repository — no central testing repository needs to be configured. Snaps not yet migrated to a colocated suite fall back to the legacy shared kenvandine/automated-ken-tests repo automatically.
Automatically trigger tests when a newer version is detected in candidate/beta/edge.
Download Workflow Template

Setup Instructions (per snap)

  1. Add the workflow template above to the snap's packaging repo at .github/workflows/snap-test.yml.
  2. Add a repository secret named SNAP_DASHBOARD_GITHUB_TOKEN with a token that has repo scope.
  3. Create YARF test suites under tests/suite/__init__.robot in that same repo.
  4. Enable "automatic testing" above and save — the dashboard will detect and use the colocated suite automatically.
